react-native-nitro-assets

Ship ML models and media outside your app binary.
iOS 26 Background Assets On-Demand Resources Play Asset Delivery
The problem

A 118.8 MB model doesn't belong in your app binary.

Bundled: every user downloads it with every update
As an asset pack: delivered by the store, updated on its own
+
📦 intent-model · model.pte + tokenizer.json
1 · Configure
Expo config plugin, plus the downloader extension Apple-hosted packs need.
// app.json
["react-native-nitro-assets", {
"packs": { "intent-model": { "path": "./asset-packs/intent-model" } },
"ios": { "backgroundAssets": { "packs": { "intent-model": "essential" } } }
}]
// workspace.config.ts (expo-native-config)
targets: [{ package: 'react-native-nitro-assets/downloader' }]
2 · Package and upload
One command builds the Apple-hosted pack from your app config.
$ npx nitro-assets package
intent-model (essential): asset-packs-out/intent-model.aar, 117.9 MB
$ xcrun altool --upload-asset-pack asset-packs-out/intent-model.aar \
--apple-id <app id> --api-key <key> --api-issuer <issuer>
= ASSET PACK IDENTIFIER: intent-model
= ASSET PACK VERSION: 2
